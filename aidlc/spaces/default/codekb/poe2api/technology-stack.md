# Technology Stack

| Area | Technologies verified in repository |
| --- | --- |
| Web and runtime | Bun 1.4.2 container, Next.js 16.3.8 with App Router, React 19.3.0, TypeScript 5.9.3 |
| Browser presentation and state | Tailwind/PostCSS and CSS modules, Lucide, TanStack Query and Table, Zustand, React Hook Form, Zod |
| Interactive tools | PixiJS for graph rendering, ECharts for charts, Monaco for advanced source editing |
| Persistence and jobs | PostgreSQL 18, Drizzle ORM 0.45.3, postgres 3.4.9, Redis 8, ioredis 6.0.0, BullMQ 6.3.11 |
| Tooling | Bun tests, Playwright 1.63.0, ESLint 9, Prettier 3, Docker Compose, GitHub Actions |

Versioned application packages are taken from `bun.lock`. Container runtime and service versions are from `Dockerfile` and `compose.yaml`.
