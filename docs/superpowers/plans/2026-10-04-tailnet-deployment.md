# Tailnet deployment implementation plan

**Goal:** Publish Exile Atlas through GitHub Actions on pushes to master, pull the image from GHCR on the authorized VPS, and serve the app only inside the tailnet.

**Architecture:** GitHub-hosted CI checks and builds the existing Bun Docker image. The deploy job joins the tailnet with the user-supplied Tailscale OIDC credential as tag:ci, then deploys the exact digest over private SSH using a dedicated repository key and the job's temporary GITHUB_TOKEN. The production Compose stack lives at /opt/stacks/exile-atlas/docker-compose.yml, with persistent PostgreSQL/Redis volumes and a loopback web listener behind Tailscale Serve HTTPS.
